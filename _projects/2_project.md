## Project Overview


This is the final project for **UW CSE 512: Data Visualization (Spring 2024)**, completed by **Mingzhuo Ma**, Jiaqi Dong, Yuhua Nie, and Logan Sun.

The project explores bird migration patterns through an interactive web-based visualization, allowing users to examine spatial and temporal migration trends.
